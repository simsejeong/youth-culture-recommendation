## 2. 문제 정의

- 고립·은둔 청년의 회복 지원에서 **취미·문화 활동**에 대한 수요가 확인되고, 전국에 문화 기반 시설도 충분히 존재함
- 그러나 **개인의 문화 성향과 고립·은둔 수준을 고려한 맞춤형 연결**이 부족함
- → 설문 기반으로 **개인별 문화 성향을 분류**하고, **회복 단계와 참여 조건을 반영한 맞춤형 문화 콘텐츠 추천**을 목표로 함

## 3. 문화 성향 분류

**K-means 군집 탐색** (청년 154명, 22개 입력 피처)
- 실루엣 점수가 k별로 0.11~0.13 수준으로 낮아, 특정 k에서 뚜렷한 분리가 확인되지 않음
- 군집이 **Q14(활동 장소)·Q16(힐링 장소)** 두 문항에 크게 의존함을 확인
  - 두 문항만으로 군집 예측 정확도 96.1%(교차검증), 두 문항 제외 후 재군집화 ARI 0.097

**2문항 규칙 기반 3유형** — 해석 가능하고 서비스에서 바로 설명할 수 있는 규칙으로 단순화

```
Q14 선호 활동 장소
├─ 집안 선호 ─────────────────────── 집콕힐링형 (75명, 48.7%)
└─ 야외 선호 → Q16 선호 힐링 장소
               ├─ 숲·공원 ────────── 야외활동형 (49명, 31.8%)
               └─ 갤러리·북카페 ──── 문화예술형 (30명, 19.5%)
```

- 유형별 Q20(선호 문화 활동) 비교 결과 '조용한 실내 문화공간'과 '스포츠'에서 유의한 차이 확인 (FDR q < 0.05)
- 나머지 활동은 차이가 뚜렷하지 않아, 3유형을 **정밀한 선호 예측이 아닌 추천 후보의 우선순위 기준**으로 활용

## 4. 문화 콘텐츠 추천 DB 구축

| 데이터 소스 | 문화 콘텐츠 | 좌표 보유율 | 컬럼 |
|---:|---:|---:|---:|
| 21개 | 58,501건 | 99.95% | 29개 (6개 분류 그룹) |

**주요 전처리** — 중복 제거·통합(이름+좌표+프로그램명, 동명 공원 0.2km 이내 2차 중복 제거) · 카테고리 적합성 필터링(식당·병원 등 오염 데이터 제거) · 가격 파싱(`N만원`, 일부 무료 표기 등) · 주소 표준화 및 TM 좌표 변환 · Naver Geocoding으로 결측 좌표 보강 · 항목 통일

**추천 속성 태깅**

| 속성 | 값 |
|---|---|
| 활동 공간 `space_type` | 실내 · 실외 · 온라인 · 혼합 |
| 참여 형태 `social_mode` | 1인 전용 · 1인 가능 · 소그룹 · 그룹 |
| 사회적 활동 강도 `social_intensity_score` | 0~3점 (수용인원 300명 이상이면 +1 보정) |
| 콘텐츠 특성 `content_mode` | 감각형 · 사고형 · 혼합 |

## 5. 추천 엔진 설계

```
전체 문화 콘텐츠 58,501건
 → ① 위치·거리 필터     5,536건
 → ② 예산 조건 필터     5,484건
 → ③ 활동 강도 필터     4,823건   (은둔 ≤ 1 · 고립 ≤ 2 · 일반 ≤ 3)
 → ④ 점수화 및 우선순위 산정
 → 최종 Top 5 추천                 (예시: 서울 · 집콕힐링형 · 은둔)
```

| 점수 규칙 | 내용 |
|---|---|
| 문화 성향 적합도 | 성향 후보 풀 안 +50점 / 풀 밖 +10점 |
| 활동 강도 적합도 | 은둔은 저강도, 일반은 고강도를 선호하도록 연속 가점 |
| 프로그램 가중치 | 은둔 -30점 / 고립 0점 / 일반 +30점 |
| 무거운 역사 콘텐츠 | 은둔 -100점 / 고립 -60점 / 일반 0점 |
| 거리 감점 | 1km당 -0.5점 (가까운 콘텐츠 우선) |
| 카테고리 다양성 | 같은 묶음 최대 2건 (유사 콘텐츠 편중 방지) |

> 온라인·DIY 콘텐츠는 거리 필터에서 제외하고, 활동 강도 통과 후보가 없으면 상한을 1단계 완화합니다.

**검증 사례** (전남 고흥 · 30분 이내 · 1만 원 미만)
- 고립·은둔 수준별: 은둔 → 온라인·DIY 중심 / 고립 → 기록관·전시관 / 일반 → 체험마을 등 그룹 활동
- 문화 성향별: 집콕힐링형 → 비대면 콘텐츠 / 야외활동형 → 공원·DIY / 문화예술형 → 전시·박물관
- 카테고리 제한으로 성향 풀 밖 콘텐츠도 후보로 활용됨을 확인

3. 노트북을 01 → 02 → 03 순서로 실행
